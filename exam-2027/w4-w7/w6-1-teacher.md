# W6-1｜篇章結構｜指示詞與段落承接（教師版）

學生版：[w6-1-student.md](w6-1-student.md)

## 目標與時間（90 分鐘）

| 時間 | 活動 | 老師觀察 |
|---|---|---|
| 0–10 | 5 字暖身；不熟的字先放入短句 | 能否說詞性與意思 |
| 10–25 | 講 3 個關鍵規則，每個請學生舉例 | 是否理解而非背名稱 |
| 25–45 | 限時讀文章 6 分鐘、4 題閱讀、逐題找證據 | 主旨、細節、文脈 |
| 45–65 | 獨立完成 P1–P6，再說每題線索 | 能否遷移規則 |
| 65–80 | 2 題整合輸出，按程度口頭或書寫 | 句子完整度 |
| 80–90 | 訂正、收斂 1–2 個弱點、交代課後複習 | 是否能自行說出錯因 |

## 單字（5 字）
- **organize**：組織
- **participant**：參加者
- **collect**：收集
- **community**：社區
- **result**：結果

## 觀念提醒
- This / These / Such a result 必須能指回前文
- 選句先看前一句的名詞和行為，再看後一句是否承接
- 事件常有 first → later → finally 的順序

## 文章閱讀題解答（4 題）
- **R1：A**。At first ... near the bus station。
- **R2：A**。many empty bottles ... nearby park。
- **R3：A**。指前一句 the park looked much better。
- **R4：A**。More participants joined。

## 獨立練習解答（6 題）
- **P1：A**。This 指前句整個行為。
- **P2：A**。邀請→人數增加。
- **P3：A**。相同主題且按時間。
- **P4：A**。These 要有前文對應複數名詞。
- **P5：A**。呼應清潔公園的結果。
- **P6：A**。接續流程。

## 整合輸出參考
1. First, we collected paper. Next, we sorted it. Finally, we recycled it.
2. The class collected 100 books. This result encouraged the teachers.

## 錯題應對
- 讀不懂文章：先標主詞與動詞，每段用 1 句中文講大意。
- 題目靠猜：每題說出一條原文依據／詞性線索後才能改答案。
- 作答慢：先抓題幹關鍵詞，不要求逐字翻譯。
- 成績 8–10／10：下次提高閱讀速度；5–7／10：下次開頭先做兩題同類題；0–4／10：先補當日最核心的一條規則。
- 課後 [review.html](review.html) 選 W6-1，看單字 /5 與規則 /3；由學生截圖回報，不自動上傳成績。

**注意：** 這些為原創教學練習，不是學測正式試題；答案依當題語境判斷，避免過度教成毫無例外的文法公式。
